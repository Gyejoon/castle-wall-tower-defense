# Business Model (BM)

> **Last Updated:** 2026-05-06 (v4.0 — minimal monetization)
> **Goal:** 큰 수익화가 아니라 운영비 보조. 강제 광고, 성장 과금, 복잡한 상점 경제는 v1에서 제외한다.

---

## 1. V1 Policy

| 원칙 | 내용 |
|------|------|
| 강제 광고 없음 | 플레이 중/결과 후 자동 광고를 넣지 않는다 |
| Pay-to-win 없음 | 유료 재화로 전투력을 직접 팔지 않는다 |
| 선택형 광고만 | 플레이어가 명확한 보상을 보고 선택한다 |
| 운영 최소화 | 매일 관리해야 하는 상점/이벤트/미션을 만들지 않는다 |

---

## 2. V1 Ad Placements

| placement_id | 노출 위치 | 보상 | 제한 |
|--------------|-----------|------|------|
| `continue_run` | 패배 화면 | HP +5, 현재 런 1회 부활 | 런당 1회 |
| `reroll_checkpoint_rewards` | checkpoint reward 선택 화면 | 3개 reward 재추첨 | checkpoint 1회당 1회 |

광고를 보지 않아도 게임의 기본 루프는 성립해야 한다. 광고는 “한 번 더 해보고 싶다”는 순간에만 붙인다.

---

## 3. Deferred Monetization

아래 항목은 v1 출시 전 구현하지 않는다.

| 항목 | 상태 | 재검토 조건 |
|------|------|-------------|
| 광고 제거 패키지 | 보류 | 광고 DAU가 의미 있게 발생한 뒤 |
| 스타터 팩 | 보류 | D7 retention 확인 뒤 |
| 다이아 상자 | 제외 | 컬렉션/메타 경제를 다시 설계할 때 |
| 월간 패스 | 제외 | 수동 운영 여력이 생긴 뒤 |
| 코스메틱 상점 | 보류 | 기본 게임이 유지되고 에셋 제작 여력이 있을 때 |
| 시즌 이벤트 | 제외 | 서버/운영 체계를 갖춘 뒤 |

---

## 4. Revenue Target

v1은 “운영비 일부 보조”가 목표다.

| 항목 | 기준 |
|------|------|
| 우선 지표 | 광고 선택률, 재시작률, 세션 길이 |
| 수익 기대 | 낮음. core loop 검증이 우선 |
| 실패 기준 | 광고를 붙여야만 게임이 진행되는 구조 |

---

## 5. KPI

필수 지표만 본다.

| KPI | 목적 |
|-----|------|
| Session Length | 평균 6~8분 목표 확인 |
| Retry Rate | “한 판 더” 확인 |
| Continue Ad Opt-in | 이어하기 광고가 자연스러운지 확인 |
| Reroll Ad Opt-in | checkpoint reward 리롤 광고가 자연스러운지 확인 |
| First Boss Reach Rate | 초반 재미 도달 확인 |
| Wave Reach Distribution | 난이도 튜닝 |

결제 전환율, ARPPU, 구독 지표는 v1에서 추적하지 않는다.

---

## 6. Parking Lot

수익화를 확장하려면 별도 문서에서 새로 설계한다.

- 다이아 경제
- 상자/천장
- 상점 카탈로그
- 출석 보상
- 시즌 패스
- 코스메틱 판매
- 복귀 유저 패키지
