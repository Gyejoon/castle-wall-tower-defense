# Tower Defense UI

타워디펜스 게임 특유의 UI 패턴과 이 프로젝트의 구체적인 구현 가이드.

## 타워 선택 독(Dock)

### 레이아웃
- 화면 하단 고정, 게임 캔버스 아래.
- 수평 그리드: 4개 기본 타워를 1행에 배치 (퓨전 타워는 해금 후 추가).
- 각 슬롯 크기: 최소 64x64px (44px 터치 타겟 + 패딩).

### 슬롯 구성
```
┌──────────┐
│  [아이콘]  │  ← 32x32 타워 스프라이트
│   50G     │  ← 비용 (gold 색상, 8px 폰트)
└──────────┘
```

### 상태
- **기본**: `colors.panel` 배경, `colors.border` 보더.
- **선택됨**: `colors.accent` 보더 (2px), 미세한 `scale(1.05)`.
- **비활성** (골드 부족): `opacity: 0.4`, 터치 불가.
- **쿨다운** (미래 기능): 오버레이로 잔여 시간 표시.

### 인터랙션 플로우
1. 타워 슬롯 탭 → `EventBus.emit('request-select-tower', { towerDefId })`
2. 그리드 위 타일 탭 → `EventBus.emit('request-place-tower', { col, row, towerDefId })`
3. 성공 시 → 골드 차감 피드백 + 타워 배치 애니메이션
4. 실패 시 → 빨간 플래시 + 피드백 메시지 (1.5초 후 사라짐)

## 타워 배치 플로우

### 비주얼 피드백
- **호버** (마우스/터치 이동): 해당 타일에 타워 실루엣 + 범위 원
- **배치 가능**: 초록 틴트 오버레이
- **배치 불가** (점유됨/경로 위): 빨간 틴트 오버레이
- **배치 완료**: 짧은 스케일 바운스 애니메이션 (타워가 "놓이는" 느낌)

### 모바일 고려사항
- 손가락이 그리드를 가리는 문제 → 터치 포인트 위에 미리보기 팝업 표시
- 길게 누르면 타워 정보 팝오버 (비용, 데미지, 범위, 특수 효과)

## 웨이브 미리보기

### 표시 조건
- 빌드 페이즈에서만 표시.
- 타워 독 위 또는 상태바 아래에 위치.

### 레이아웃
```
다음 웨이브: 고블린 ×5  오크 ×3  트롤 ×1
```
- 유닛 아이콘(16x16) + 이름(8px) + 수량.
- 수평 나열, 간격 8px.
- 보스 유닛은 `colors.danger` 하이라이트.

## 빌드/전투 페이즈 전환

### 빌드 페이즈 UI
- 타워 독 확장 표시
- 웨이브 미리보기 표시
- 카운트다운 타이머 (상태바 내)
- 골드 숫자 강조 (타워 구매 유도)
- "전투 시작" 버튼 (카운트다운 스킵)

### 전투 페이즈 UI
- 타워 독 축소 (선택만 가능, 배치는 불가)
- 웨이브 미리보기 숨김
- HP 변화 강조
- 웨이브 프로그레스 표시 (남은 유닛 수)

### 전환 애니메이션
- 독 확장/축소: `max-height` + `opacity` CSS transition (200ms).
- 웨이브 미리보기: 슬라이드다운/업 (150ms).
- 페이즈 배지: 색상 크로스페이드.
- 전체 전환 시간: 200ms 이내. 게임 흐름을 끊지 않을 것.

## 고스트 배틀 PvP UI

### 프레셔(Pressure) 선택 패널
- 빌드 페이즈에서 3개 선택지 표시: 공격 / 방어 / 투자.
- 각 선택지: 아이콘 + 짧은 설명 (1줄).
- 선택 후 확인 상태 표시 (체크마크 + 비활성화).
- 위치: 타워 독 위, 웨이브 미리보기 아래.

### 매치 결과 오버레이
- 게임 종료 시 전체 화면 오버레이.
- 상태별 색상:
  - 승리: `colors.success` (#7ab648) 강조
  - 패배: `colors.danger` (#c03020) 강조
  - 무승부: `colors.accent` (#c8a04a) 강조
- 핵심 통계: 처치 수, 생존 HP, 사용 골드.
- "로비로 돌아가기" 버튼 (하단 중앙, 44px 이상).

### 고스트 경고
- 상대 프레셔가 적용될 때 짧은 경고 배너 (상단에서 슬라이드다운, 2초 후 사라짐).
- `colors.danger` 배경 + 흰색 텍스트.
