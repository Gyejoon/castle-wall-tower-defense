# Game HUD Design

타워디펜스 게임의 HUD(Heads-Up Display) 디자인 가이드.

## 정보 계층

### 1차 정보 (항상 보임, 큰 크기)
- **HP (Lives)**: danger 색상 (#c03020) 아이콘 + 숫자. 변경 시 빨간 플래시.
- **골드**: gold 색상 (#f0d060) 아이콘 + 숫자. 변경 시 반짝임 효과.

### 2차 정보 (상시 보이지만 1차보다 작음)
- **웨이브 카운터**: "Wave 3/10" 형태. text 색상.
- **카운트다운**: 빌드 페이즈에서만. 5초 이하일 때 danger 색상으로 전환.

### 3차 정보 (컨텍스트에 따라 표시)
- **페이즈 표시**: "빌드 중" / "전투 중" 배지.
- **선택된 타워 정보**: 이름, 비용, 특수 효과.

## 상태바 레이아웃

```
┌──────────────────────────────────────┐
│ [왕국의 방어선]  ♥20  ◆150  Wave 3/10 │
│                         [빌드 중 15s] │
└──────────────────────────────────────┘
```

- 높이: 최소 (44-56px). 게임 영역을 최대한 확보.
- 배경: `colors.panel` (#2a2010) 또는 반투명.
- 보더: 하단에 1px `colors.border` (#4a3a20).
- 패딩: 8-12px 좌우, 4-8px 상하.

## 숫자 변경 피드백

### 골드 변경
- **증가**: 숫자가 잠시 `colors.gold`로 밝아졌다가 원래 색으로 돌아감.
- **감소** (타워 구매): 숫자 옆에 "-50" 텍스트가 떠오르며 페이드아웃.
- CSS: `transition: color 200ms ease-out` 또는 짧은 scale bounce.

### HP 변경
- **감소**: 숫자가 `colors.danger`로 잠시 커졌다가 원래 크기로. 배경이 빨간색 플래시.
- 심각한 감소 (HP ≤ 5): 숫자 자체가 계속 빨간색으로 유지.

### 웨이브 전환
- 카운터 업데이트 시 슬라이드업 전환.
- 새 웨이브 시작 시 짧은 스케일 펄스.

## 픽셀 폰트 가독성

### 최적 크기 (Press Start 2P 기준)
- **대형 (중요 숫자)**: 14-16px — HP, 골드 숫자
- **중형 (라벨)**: 10-12px — 웨이브 카운터, 버튼 라벨
- **소형 (보조 정보)**: 8px — 타워 비용, 보조 텍스트

### 주의사항
- Press Start 2P는 짝수 크기에서 가장 선명 (10, 12, 14, 16px).
- 홀수 크기는 서브픽셀 렌더링으로 흐릿해질 수 있음.
- `letter-spacing: 1px` 추가하면 좁은 공간에서 가독성 향상.
- `line-height`는 폰트 크기의 1.6-2.0배 (픽셀 폰트는 기본 line-height가 낮음).

## 반투명 HUD 배경

### 패턴
```css
background: rgba(26, 18, 8, 0.85);  /* colors.bg at 85% */
backdrop-filter: blur(4px);           /* 선택적 — 성능 고려 */
```

### 주의사항
- `backdrop-filter`는 모바일에서 성능 영향. 꼭 필요한 경우만.
- 대안: 불투명 배경에 미세한 그라디언트 (`linear-gradient(to bottom, colors.panel, transparent)`).
- 게임 캔버스 위에 겹쳐지는 경우만 반투명 사용. 캔버스 외부 영역은 불투명.
