## 1. BM 구조

| BM 종류 | 예시 | 금지선 |
|--------|------|-------|
| Premium | 광고 제거 패키지 / 스타터 팩 | 진입장벽 금지 |
| IAP | 골드 팩 / 성장 재화 / 스타터 번들 | pay-to-win 금지 |
| Ads | 전투 후 보상형 광고 / 추가 골드 | 강제 광고 금지 |
| Cosmetic | 로비 스킨 / 타워 스킨 / 이펙트 스킨 | 밸런스 영향 없음 |
| Subscription | 월간 성장 패스 / 출석 강화 | 보상 과잉으로 격차 금지 |

**BM 체크리스트**
- [ ] 과금이 코어 재미를 해치지 않는가
- [ ] 광고 노출이 피로감을 주지 않는가
- [ ] no-pay 유저도 게임이 성립하는가
- [ ] 구매 타이밍이 자연스러운가

## 3. 가챠 / 상자 시스템

> 상세 확률·쿨타임은 [02-balance-sheet.md](./02-balance-sheet.md) §2, §4 참조.

### 상자 4종

| 상자 | 비용 | 획득 | 쿨타임 |
|------|------|------|-------|
| 무료 상자 | 0 | 히든 타워 1개 (랜덤 등급) | 24h (일 1회) |
| 광고 상자 | 광고 시청 | 히든 타워 1개 (랜덤 등급) | 8h (일 3회) |
| 다이아 상자 1개 | 💎 100 | 히든 타워 1개 | 없음 |
| 다이아 상자 10개 | 💎 900 (10% 할인) | 히든 타워 10개 + tier3+ 보장 | 없음 |

### 등급 확률

| tier | 이름 | 확률 |
|------|------|------|
| 1 | 일반 | 40% |
| 2 | 레어 | 35% |
| 3 | 유니크 | 18% |
| 4 | 에픽 | 6% |
| 5 | 전설 | 1% |

> 천장(pity): 50연차 tier4 이하 연속 시 다음 상자에서 tier5 확정.

### 상자 오픈 연출

| 단계 | 연출 |
|------|------|
| 상자 등장 | 드롭 애니메이션 + 등급별 이펙트 색상 |
| 오픈 | 열림 애니메이션 + 빛 이펙트 (tier3+ 강화) |
| 결과 공개 | 타워 실루엣 → 컬러 전환 + 등급 텍스트 |
| 컬렉션 등록 | 신규 시 "NEW!" 뱃지 + 도감 등록 연출 |
