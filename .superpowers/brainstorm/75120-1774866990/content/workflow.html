워크플로우: 명령어 사용 시나리오

impeccable 명령어가 게임 UI 컨텍스트에서 어떻게 동작하는지

초기 셋업 (1회)

/teach-impeccable → .impeccable.md 생성/업데이트
↳ 이미 작성한 디자인 컨텍스트 기반으로 동작

일상 워크플로우

UI 품질 점검
/audit → 5개 차원 (접근성, 성능, 테마, 반응형, 안티패턴) 점검
↳ .impeccable.md의 "픽셀 미학", "모바일 퍼스트" 맥락에서 평가
↳ game-ui-design reference가 Canvas/DOM 통일감도 체크

예시 출력: "상태바의 골드 텍스트가 배경 대비 3.2:1 — AA 미달. #f0d060 → #f5d86a로 조정 권장"
디자인 일관성 맞추기
/normalize → 디자인 시스템 표준에 맞춤
↳ tokens.ts 색상, 간격, 폰트 사이즈가 일관적인지 검사

/arrange → 레이아웃, 간격, 구성 수정
↳ 상태바↔캔버스↔독 간 간격 리듬 체크
새 UI 기능 추가 시
/game-ui-design → 게임 UI 가이드라인 참조하며 작업
↳ React/Phaser 경계, 터치 타겟, HUD 계층 원칙 적용

/polish → 작업 완료 후 최종 품질 패스
↳ 정렬, 타이포, 색상 일관성, 인터랙션 상태, 마이크로인터랙션
애니메이션 & 모션
/animate → 의미 있는 모션 추가
↳ 골드 변경 시 숫자 바운스, 페이즈 전환 슬라이드, 매치 결과 등장 효과
↳ 60fps 게임 루프와 충돌하지 않는 CSS 애니메이션 위주
색상 & 타이포
/colorize → 전략적 색상 적용 (tokens.ts 기반)
/typeset → 픽셀 폰트 계층, 크기 일관성 수정
