# 대장정 콘텐츠 확장 설계

> **Date:** 2026-04-08
> **Status:** Draft
> **Goal:** 1-2시간 완주 가능한 현재 콘텐츠를 270시간+(하루 3시간 × 90일+) 분량으로 확장

---

## 1. 배경

현재 게임은 3스테이지(30웨이브), 레벨 게이트 2개(Lv.3, Lv.7), 단일 난이도로 1-2시간이면 모든 콘텐츠를 소진한다. 타워 18종의 레벨링/승급도 빠르게 완료되어 장기 플레이 동기가 없다.

**확장 전략:** 수평(스테이지 대량) + 수직(난이도 레이어) 복합 확장. 순수 난이도 벽으로 진행 속도 제어 (스태미나/타임 게이트 없음).

## 2. 월드맵 구조 — 6월드 × 8스테이지 (48스테이지)

중세 판타지 세계관. 왕국 변경에서 마왕의 왕좌까지의 대장정.

| w2_forge | 불의 단조장 | 드워프 단조장, 화염 마족 점령 | W1 ★1 전체 | 8-18 | 용광로 폭발 |
| w3_tower | 마탑 성채 | 타락한 마법사 탑, 마력 폭주 | W2 ★1 전체 | 18-30 | 마력 폭주 |

### 2.2 월드 기믹 상세

**W1 변경의 숲** — 기믹 없음. 기본 시스템(배치, 에너지, 덱) 학습. 기존 forest_gate를 8스테이지로 확장.

**W2 불의 단조장 — 용광로 폭발**
- 특정 타일이 주기적으로 용광로 분출 (8초 ON / 12초 OFF)
- 분출 중 해당 타일의 타워 비활성화
- ★2: 분출 주기 단축 (6초 ON / 10초 OFF)
- ★3: 분출 범위 확대 (인접 1타일 포함)
- 대응: 안전 타일 파악, Water 속성, 유동적 배치

**W3 마탑 성채 — 마력 폭주**
- 3웨이브마다 무작위 2×2 영역에 마력 폭발
- 폭발 영역 타워 3초 스턴
- 마법진 타일(맵에 2-3개 고정)에 배치 시 면역 + 공격력 +15%
- ★2: 폭발 빈도 2웨이브마다
- ★3: 폭발 범위 3×3, 마법진 타일 1개로 축소
- 대응: 마법진 활용, CC 체인, 분산 배치

**W4 왕가의 지하묘지 — 묘지 부활**
- 처치한 적이 30% 확률로 약화 상태(HP 40%)로 부활
- 신성 계열 타워(Holy Shrine, Divine Throne 등)로 처치 시 부활 불가 — 속성이 아닌 타워 역할(role) 기반 판정
- 해골 더미 타일 근처 사망 시 부활 확률 100%
- ★2: 부활 확률 50%, HP 60%
- ★3: 부활 확률 70%, HP 80%, 부활 시 CC 면역 3초
- 대응: 신성/정화 타워 필수, 해골 더미 타일 회피

**W5 몰락한 왕국 — 역병 확산**
- 매 웨이브 시작 시 역병 안개 확산
- 안개 영역 타워: 매초 공격력 -2% 누적 (최대 -40%)
- 정화탑(신성 계열)으로 주변 3×3 안개 제거 가능
- 적 사망 시 역병 웅덩이 생성 (해당 타일 5초간 안개)
- ★2: 안개 감소율 -3%/초, 정화 범위 2×2
- ★3: 안개 감소율 -4%/초, 웅덩이 지속 10초
- 대응: 정화 타워 + DPS 균형, 적 처치 위치 관리

**W6 마왕의 왕좌 — 마왕의 시련**
- 스테이지마다 이전 월드 기믹 중 1개를 랜덤 적용
- 추가로 고유 제약 1개 부여:
  - 덱 4→3개
  - 에너지 회복 -50%
  - 적 출현 시 3초 무적
  - 타워 배치 후 10초간 공격 불가
  - 보스 CC 완전 면역
- ★2: 제약 2개 동시 적용
- ★3: 기믹+제약 동시 2개 적용 (총 3개 변수)
- 대응: 풀세팅 로스터, 모든 기믹 대응력

## 3. ★ 별 등급 시스템

각 스테이지는 ★1/★2/★3 세 단계 난이도로 도전 가능.

### 3.1 등급별 설정

| 항목 | ★1 정복 | ★2 정예 | ★3 지옥 |
|------|---------|---------|---------|
| HP 배수 | 1.0× | 2.5× | 5.0× |
| 방어 배수 | 1.0× | 1.5× | 2.5× |
| 속도 배수 | 1.0× | 1.2× | 1.4× |
| CC 저항 | 0% | 20% | 40% |
| 기믹 강도 | 약 | 강화 | 극한 |
| 클리어 조건 | 생존 | HP 50%+ 유지 | HP 100% 유지 (무피격) |
| 골드 보상 | 1× | 2.5× | 5× |
| XP 보상 | 1× | 2× | 3× |
| 각성석 드롭 | 0 | 1-2개 | 3-5개 |

### 3.2 해금 규칙

- ★1: 해당 월드 진입 시 자동 해금
- ★2: 해당 월드 ★1 전체 클리어
- ★3: 해당 월드 ★2 전체 클리어

## 4. 타워 육성 시스템 (변경사항)

### 4.1 승급 시 레벨 리셋 (변경)

기존: 승급 성공 시 레벨 유지
변경: **승급 성공 시 Lv.1로 리셋**

타워 풀육성 경로:
```
Normal Lv.1→20 → Rare 승급(20%) → Lv.1 리셋
Rare Lv.1→30   → Unique 승급(10%) → Lv.1 리셋
Unique Lv.1→50 → Epic 승급(5%) → Lv.1 리셋
Epic Lv.1→50   (최종)
= 총 150레벨 + 승급 실패 재시도 비용
```

### 4.2 각성 시스템 (신규)

Epic Lv.50 달성 후 추가 성장 단계. 각 단계마다 고유 스킬 해금.

| 각성 단계 | 필요 재료 | 효과 | 소요 시간 |
|----------|---------|------|---------|
| 1각성 | 각성석 5 + 동일 타워 중복 1체 | 스탯 ×1.2 + 패시브 스킬 1 | ~3h |
| 2각성 | 각성석 15 + 동일 타워 중복 2체 | 스탯 ×1.5 + 패시브 스킬 2 | ~8h |
| 3각성 | 각성석 30 + 동일 타워 중복 3체 + 월드 보스 특수 재료 | 스탯 ×2.0 + 궁극 스킬 (액티브) | ~15h |

### 4.3 각성 재료 획득 경로

**각성석:**
- ★2 스테이지 클리어: 확정 1-2개
- ★3 스테이지 클리어: 확정 3-5개
- 월드 보스(W4-W6 최종 보스): 10-20개
- 주간 미션 완료: 주 5개
- 업적 보상: 일회성 지급
- 향후 다이아 상점 판매 검토 (Phase 5)

**중복 타워:** 가챠에서 이미 보유한 타워 재획득 시 자동 중복 조각 변환

**월드 보스 특수 재료:** W4-W6 보스 ★2+ 클리어 시 드롭 (3각성 전용)

## 5. 전투력 시스템 (신규)

모든 보유 타워의 파워를 합산한 종합 지표. 프로필 화면에 표시.

### 5.1 공식

```
전투력 = Σ (기본ATK × 등급배수 × 레벨배수 × 각성배수)

등급배수: Normal 1.0 / Rare 1.1 / Unique 1.25 / Epic 1.45
레벨배수: 1 + (level - 1) × 0.03
각성배수: 0각성 1.0 / 1각성 1.2 / 2각성 1.5 / 3각성 2.0
```

### 5.2 마일스톤

100 → 500 → 1,000 → 3,000 → 5,000 → 10,000 → 20,000 → 50,000

각 마일스톤 달성 시 업적 보상 + 프로필 프레임 변경.

## 6. 업적 시스템 (신규)

장기 목표 제시 + 다이아 보상. 총 ~200개 업적, 4카테고리.

### 6.1 카테고리별 예시

**전투력 업적 (~15개)**
- 전투력 100/500/1K/3K/5K/10K/20K/50K 달성 → 💎 50~2,000

**레벨 업적 (~20개)**
- 프로필 레벨 5/10/20/30/50/75/99 달성 → 💎 30~1,000

**타워 육성 업적 (~50개)**
- 첫 Lv.10/20/30/50 달성
- 첫 Rare/Unique/Epic 승급
- 첫 1/2/3각성
- 전 타워 Lv.50/Epic/3각성 달성 (최종 업적)

**진행 업적 (~100개+)**
- 월드별 ★1/★2/★3 전체 클리어
- 보스 10/50/100/500회 격파
- 총 웨이브 100/500/1000/5000 클리어
- 특수 조건: 무피격 보스 격파, 동일 속성 덱 클리어, 타워 2개로 클리어 등

### 6.2 보상 총액

총 ~25,000💎 (10연차 ~27.7회분). 일회성이므로 장기적으로 다이아 공급 감소 → 미션 시스템이 지속 공급 담당.

## 11. 검증 방법

1. **수치 검증:** 밸런스 시트에 각 월드 × ★ 등급별 적 HP/방어/속도 계산 후, 권장 전투력 범위와 교차 검증
2. **경제 검증:** 레벨 리셋 후 총 골드 소비량 vs 스테이지별 골드 수입 균형 확인
